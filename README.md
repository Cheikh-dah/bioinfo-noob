🧬 DNA Sequence Analysis

This repository contains four Python projects related to DNA sequence analysis and bioinformatics. Each project focuses on a different way to work with DNA sequences, from calculating nucleotide composition to comparing sequences using alignment algorithms.

Projects
1. DNA Sequence Analysis

Analyzing DNA sequences by working with the four nucleotides: adenine (A), thymine (T), cytosine (C), and guanine (G).

2. Needleman–Wunsch Global Sequence Alignment

Implementing the Needleman–Wunsch algorithm to align two DNA sequences across their full lengths. The algorithm uses dynamic programming with match scores, mismatch penalties, and gap penalties.

3. GC Content Analysis

Calculating the percentage of guanine (G) and cytosine (C) in a DNA sequence.

Formula:

GC%=G+CSequence length×100
4. Reverse Complement

Generating the reverse complement of a DNA sequence by replacing each nucleotide with its complementary base and reversing the sequence.

Base-pair rules:

Base	Complement
A	T
T	A
C	G
G	C

Running the Code

Make sure Python 3 is installed. Run the script for the project you want to use:

python dna.py


Replace dna.py with the appropriate filename in your repository.
